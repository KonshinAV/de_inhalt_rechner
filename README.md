# inhalt_rechner

Консольный калькулятор для приблизительного расчёта дохода в Германии: переводит **brutto в netto** по часовой ставке и показывает, из чего складываются удержания.

Все параметры задаются в одном файле `config.yml`, поэтому для нового расчёта достаточно поменять пару чисел и запустить скрипт.

## Возможности

- Расчёт brutto и netto **в неделю, в месяц и в год**
- Социальные взносы работника: Rentenversicherung, Arbeitslosenversicherung, Krankenversicherung (с учётом Zusatzbeitrag вашей кассы), Pflegeversicherung (с учётом количества детей и доплаты для бездетных)
- Подоходный налог (Lohnsteuer) по базовому тарифу 2026 года
- Классы налогов **1, 3 и 4** (для класса 3 используется splitting-тариф)
- Солидарная надбавка (Solidaritätszuschlag) с зоной плавного перехода
- Церковный налог (Kirchensteuer)
- Учёт потолков взносов (Beitragsbemessungsgrenze)
- Предупреждения о Minijob и Übergangsbereich (Midijob)

## Требования

- Python 3.8+
- [PyYAML](https://pypi.org/project/PyYAML/) (указан в `requirements.txt`)

Установка зависимостей:

```bash
pip install -r requirements.txt
```

## Быстрый старт

```bash
git clone https://github.com/KonshinAV/inhalt_rechner.git
cd inhalt_rechner
pip install -r requirements.txt
python income_calculator.py
```

Скрипт читает `config.yml`, который должен лежать в одной папке с `income_calculator.py`.

## Настройка

Откройте `config.yml` и укажите свои значения:

```yaml
# --- Основные параметры ---
hourly_rate: 15.39      # Часовая ставка brutto, в евро
hours_per_week: 38      # Количество рабочих часов в неделю

# --- Дополнительные параметры (можно не менять) ---
optional:
  tax_class: 4                     # Класс налога: 1, 3 или 4
  children: 0                      # Количество детей (влияет на Pflegeversicherung)
  church_tax_rate: 0.0             # Церковный налог: 0.0 (нет), 0.08 или 0.09
  health_insurance_extra_rate: 2.9 # Zusatzbeitrag вашей Krankenkasse, в процентах
  weeks_per_year: 52               # Количество оплачиваемых недель в году
```

| Параметр | Обязательный | По умолчанию | Описание |
|---|---|---|---|
| `hourly_rate` | да | — | Часовая ставка brutto, € |
| `hours_per_week` | да | — | Рабочих часов в неделю |
| `tax_class` | нет | `1` | Класс налога: `1`, `3` или `4` |
| `children` | нет | `0` | Количество детей |
| `church_tax_rate` | нет | `0.0` | Ставка церковного налога: `0.08` (Бавария, Баден-Вюртемберг) или `0.09` (остальные земли) |
| `health_insurance_extra_rate` | нет | `2.9` | Zusatzbeitrag кассы в процентах (работник платит половину) |
| `weeks_per_year` | нет | `52` | Оплачиваемых недель в году |

Блок `optional` можно целиком удалить — тогда будут использованы значения по умолчанию.

## Пример вывода

Для настроек из `config.yml` выше:

```text
Ставка: 15,39 €/час | 38 ч/нед | Steuerklasse 4
====================================================
                        Brutto             Netto
----------------------------------------------------
В неделю              584,82 €          415,18 €
В месяц             2 534,22 €        1 799,11 €
В год              30 410,64 €       21 589,33 €
====================================================
Netto составляет 71.0% от brutto

Удержания в год:
  Rentenversicherung            2 828,19 €
  Arbeitslosenversicherung        395,34 €
  Krankenversicherung           2 660,93 €
  Pflegeversicherung              729,86 €
  Lohnsteuer                    2 207,00 €
  Solidaritätszuschlag              0,00 €

Расчёт приблизительный; точные значения — в Lohnabrechnung.
```

## Как это работает

1. **Brutto** = ставка × часы в неделю × количество недель.
2. **Социальные взносы** считаются от brutto с учётом годовых потолков (101 400 € для пенсионного страхования и страхования от безработицы, 69 750 € для медицинского и страхования по уходу).
3. **Налогооблагаемый доход** = brutto − паушальные вычеты (Werbungskosten 1 230 €, Sonderausgaben 36 €) − социальные взносы.
4. **Подоходный налог** считается по формулам тарифа 2026 года (необлагаемый минимум 12 348 €).
5. **Soli и церковный налог** начисляются поверх подоходного налога.
6. **Netto** = brutto − социальные взносы − налоги.

Константы вынесены в начало `income_calculator.py`, так что при изменении законодательства их легко обновить.

## Ограничения

Это **приближённый расчёт**, а не замена официальному расчёту зарплаты. В частности:

- Vorsorgepauschale заменена упрощением: из налогооблагаемой базы вычитаются фактические социальные взносы.
- Не поддерживаются классы налогов 2, 5 и 6.
- Не учитываются Kinderfreibetrag, индивидуальные Freibeträge, доплаты, премии, Sachbezüge и т. п.
- Для Midijob (доход примерно от 603 € до 2 000 € в месяц) взносы реально ниже, поэтому настоящий netto будет немного выше расчётного.
- Для Minijob (до 603 € в месяц) расчёт неприменим: взносы платит работодатель.
- Специфика отдельных земель (например, особые ставки Pflegeversicherung в Саксонии) не учитывается.

Точные значения всегда указаны в вашей **Lohnabrechnung**.
